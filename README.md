# Nanyang Studios

Static marketing website for Nanyang Studios — a Singapore and mainland China based company running innovation tours and corporate field trips across Asia.

## Structure

- `index.html` — page markup and content
- `styles.css` — styling
- `script.js` — mobile nav toggle, footer year, contact form handling

## Running locally

No build step required. Open `index.html` directly in a browser, or serve the folder:

```
npx serve .
```
